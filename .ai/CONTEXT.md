# AI Assistant Context

Этот файл — точка входа для AI-ассистентов, работающих с репозиторием **EvgeniyTsupikov/CapitansJournal**.

## Начало работы

Перед любой задачей необходимо:

1. Прочитать этот файл, `.ai/CHANGELOG_AI.md` и остальные файлы в `.ai/`.
2. Точечно изучить только файлы проекта, напрямую относящиеся к задаче.
3. Сохранять и дополнительно фиксировать актуальные правила репозитория.

## Правила изменений

- Писать чистый, понятный и поддерживаемый код.
- Предпочитать стандартные средства языка/фреймворка и уже используемые зависимости.
- Не добавлять новую зависимость, если задача надёжно решается имеющимися средствами. Если зависимость всё же необходима, кратко обосновать выбор в журнале изменений.
- Минимизировать область изменений, не рефакторить сторонний код без явного запроса.
- Не нарушать существующее поведение и учитывать пограничные случаи и ошибки.
- После любого изменения проекта обновлять `.ai/CHANGELOG_AI.md`.

## Гигиена журнала

- Формат даты: `ГГГГ-ММ-ДД ЧЧ:MM` с часовым поясом, если известен.
- Не записывать секреты, ключи, пароли, токены, личные данные или пользовательский контент.
- При обновлении этого файла отметить изменение в журнале.

## Основные файлы репозитория

- `README.md` — описание проекта.
- `pubspec.yaml` — зависимости и метаданные Flutter-проекта.
- `analysis_options.yaml` — правила статического анализа Dart.
- `lib/` — основной код приложения.
- `test/` — тесты.
- Платформенные каталоги: `android/`, `linux/`, `windows/`, `web/`.

## Другие файлы `.ai/`

- `.ai/CHANGELOG_AI.md` — обязательный журнал изменений AI-агентов.
