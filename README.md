# Captain's Journal (Капитанский журнал)

Приватный дневник и заметки для Android на Flutter. Записи группируются по дням, есть календарный вид, корзина с восстановлением и журнал действий. Всё хранится на устройстве: без аккаунтов, без облака, без трекеров.

> **Статус:** ранняя версия (1.0.0), проект активно развивается. Планы и дорожная карта: [см. ниже](#дорожная-карта).

## Возможности

### Записи
- Быстрое добавление записи, время сохраняется автоматически
- Редактирование текста, отдельное изменение даты и времени
- Группировка по дням, сворачивание дня, «липкий» заголовок даты
- Копирование всех записей дня в буфер обмена
- Черновик в поле ввода сохраняется при выходе из приложения

### Календарь
- Табличный вид: дата и записи за день (с временем)
- Переключение между месяцами

### Корзина
- Удалённые записи попадают в корзину, а не стираются сразу
- Восстановление, окончательное удаление, очистка корзины
- Автоудаление через 30 дней (проверка при запуске), отображается оставшийся срок

### Журнал действий
- История операций: создание, редактирование текста, изменение даты и времени, удаление, восстановление
- Разные иконки и цвета для типов действий
- Хранятся последние 1000 записей журнала

### Настройки
- Светлая и тёмная тема
- Русский и английский язык
- Статистика: количество записей и дней с записями

## Приватность

Приложение не обращается к сети и не отправляет данные никуда. Все данные лежат локально на вашем устройстве. Резервное копирование и перенос на другое устройство пока не реализованы (см. дорожную карту).

## Установка и запуск

### Требования
- Flutter SDK 3.9.2 или выше
- Android Studio или VS Code с расширением Flutter

### Запуск

```bash
flutter pub get
flutter run
```

### Сборка APK

```bash
flutter build apk --release
```

## Технические детали

- Данные хранятся локально через `shared_preferences` (JSON): записи, корзина, журнал, черновик, тема, язык. Это временное решение, планируется переход на новое хранилище.
- Зависимости: `flutter`, `flutter_localizations`, `intl`, `shared_preferences`, `cupertino_icons`.

### Формат данных (текущий)

```json
// Запись
{ "text": "Текст записи", "createdAt": "2025-01-15T10:30:00.000Z" }

// Удалённая запись
{ "note": { }, "deletedAt": "2025-01-15T10:30:00.000Z" }

// Действие
{
  "id": "1234567890",
  "action": "create|edit|delete|restore|change_date|change_time",
  "noteText": "Текст записи",
  "timestamp": "2025-01-15T10:30:00.000Z",
  "metadata": { }
}
```

## Разработка

### Добавить язык
1. Откройте `lib/l10n/app_localizations.dart` и добавьте ключи в `_localizedValues`
2. Добавьте локаль в `supportedLocales` в `main.dart`

### Добавить тип действия
1. Добавьте тип в `ActionLog.actionName` и `ActionLog.actionNameEn`
2. Добавьте иконку в `LogsPage._getActionIcon()`
3. Добавьте цвет в `LogsPage._getActionColor()`
