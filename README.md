# Мои заметки (My Notes)

Приложение для ведения дневника и заметок с поддержкой календарного вида, логирования действий и корзины с восстановлением.

## 📱 Описание

"Мои заметки" - это простое и удобное приложение для ведения личного дневника и заметок. Приложение позволяет создавать заметки, группировать их по датам, просматривать в календарном формате, отслеживать историю действий и восстанавливать удаленные записи.

## ✨ Основные функции

### 📝 Управление заметками
- **Создание заметок** - быстрое добавление заметок с автоматическим сохранением времени
- **Редактирование** - изменение текста заметок
- **Изменение даты и времени** - возможность изменить дату и время создания заметки отдельно
- **Удаление** - перемещение заметок в корзину вместо полного удаления
- **Группировка по датам** - автоматическая группировка заметок по дням
- **Сворачивание/разворачивание** - возможность скрывать/показывать заметки за конкретный день
- **Липкий заголовок** - заголовок текущей даты остается видимым при прокрутке
- **Копирование дня** - копирование всех заметок за день в буфер обмена

### 📅 Календарный вид
- **Табличный формат** - просмотр заметок в виде таблицы с колонками "Дата" и "КЖ лог"
- **Навигация по месяцам** - переключение между месяцами с помощью кнопок
- **Группировка по дням** - все заметки за день объединены в одну ячейку
- **Отображение времени** - каждая заметка в ячейке отображается с временем создания

### 🗑️ Корзина
- **Восстановление** - возможность восстановить удаленные заметки
- **Автоматическое удаление** - заметки автоматически удаляются через 30 дней
- **Индикатор времени** - отображение оставшихся дней до окончательного удаления
- **Постоянное удаление** - возможность удалить заметку навсегда с подтверждением
- **Очистка корзины** - массовое удаление всех заметок из корзины

### 📊 Логирование действий
- **История действий** - отслеживание всех операций с заметками:
  - Создание заметок
  - Редактирование текста
  - Изменение даты
  - Изменение времени
  - Удаление заметок
  - Восстановление заметок
- **Визуальное отображение** - разные иконки и цвета для разных типов действий
- **Детальная информация** - отображение времени действия и текста заметки

### ⚙️ Настройки
- **Темная/светлая тема** - переключение между темами с сохранением выбора
- **Язык интерфейса** - поддержка русского и английского языков
- **Статистика** - отображение общего количества заметок и дней с заметками
- **Информация о приложении** - версия и описание

### 💾 Автосохранение
- **Черновик** - текст в поле ввода автоматически сохраняется при выходе из приложения
- **Автоматическое сохранение** - все изменения сохраняются автоматически
- **Локальное хранение** - все данные хранятся локально на устройстве

## 📖 Использование

### Создание заметки
1. Введите текст в поле "Введите заметку..." в верхней части экрана
2. Нажмите кнопку отправки (иконка самолета) или Enter
3. Заметка автоматически сохранится с текущей датой и временем

### Редактирование заметки
1. Долгое нажатие на заметку
2. Выберите "Редактировать текст"
3. Измените текст и нажмите "Сохранить"

### Изменение даты/времени
1. Долгое нажатие на заметку
2. Выберите "Изменить дату" или "Изменить время"
3. Выберите новую дату/время в диалоговом окне

### Удаление заметки
1. Долгое нажатие на заметку
2. Выберите "Удалить"
3. Подтвердите удаление
4. Заметка переместится в корзину

### Восстановление из корзины
1. Нажмите иконку корзины в верхней панели
2. Найдите нужную заметку
3. Нажмите зеленую иконку восстановления

### Просмотр логов
1. Нажмите иконку истории в верхней панели
2. Просмотрите список всех действий с заметками

### Календарный вид
1. Перейдите на вкладку "Календарь" в верхней панели
2. Используйте кнопки влево/вправо для переключения месяцев
3. Просматривайте заметки в табличном формате

### Настройки
1. Нажмите иконку настроек в верхней панели
2. Переключите тему, измените язык или просмотрите статистику

## 🛠️ Технические детали

### Зависимости
- `flutter` - SDK Flutter
- `flutter_localizations` - поддержка локализации
- `intl` - интернационализация
- `shared_preferences` - локальное хранение данных
- `cupertino_icons` - иконки iOS стиля

### Хранение данных
Все данные хранятся локально на устройстве с использованием `SharedPreferences`:
- Заметки (`notes_json`)
- Удаленные заметки (`deleted_notes_json`)
- Логи действий (`action_logs_json`)
- Черновик текста (`draft_text`)
- Настройки темы (`isDarkTheme`)
- Язык интерфейса (`languageCode`)

### Автоматическая очистка
- Удаленные заметки автоматически удаляются через 30 дней
- Проверка выполняется при каждом запуске приложения
- Логи действий ограничены 1000 последними записями

### Локализация
Приложение поддерживает два языка:
- Русский (по умолчанию)
- English

Переключение языка доступно в настройках.

## 🎨 Особенности интерфейса

### Темы
- **Светлая тема** - классический светлый интерфейс

- Выбор темы сохраняется между сеансами

### Адаптивность
- Поддержка различных размеров экранов

- Адаптивные отступы и размеры элементов

## 📝 Формат данных

### Заметка (Note)
```dart
{
  "text": "Текст заметки",
  "createdAt": "2025-01-15T10:30:00.000Z"
}
```

### Удаленная заметка (DeletedNote)
```dart
{
  "note": { /* Note object */ },
  "deletedAt": "2025-01-15T10:30:00.000Z"
}
```

### Лог действия (ActionLog)
```dart
{
  "id": "1234567890",
  "action": "create|edit|delete|restore|change_date|change_time",
  "noteText": "Текст заметки",
  "timestamp": "2025-01-15T10:30:00.000Z",
  "metadata": { /* Дополнительные данные */ }
}
```

## 🔧 Разработка

### Добавление нового языка
1. Откройте `lib/l10n/app_localizations.dart`
2. Добавьте новый ключ в `_localizedValues`
3. Добавьте локаль в `supportedLocales` в `main.dart`

### Добавление нового типа действия
1. Добавьте новый тип в `ActionLog.actionName` и `ActionLog.actionNameEn`
2. Добавьте соответствующую иконку в `LogsPage._getActionIcon()`
3. Добавьте цвет в `LogsPage._getActionColor()`
